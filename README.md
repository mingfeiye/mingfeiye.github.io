# Mingfei Ye: personal site

Plain static HTML/CSS with no JavaScript and no build step. Project pages are generated by `../src/build_pages.py` (or edit the HTML directly).

    index.html              home page
    projects/*.html         one page per project
    style.css
    assets/                 images; assets/thumbs/ holds the project-list thumbnails

## Headshot
Save a square photo as `assets/me.jpg`. It replaces the placeholder automatically, with no code change. It's shown as a 148 px square with slightly rounded corners (104 px on phones), so 600×600 px is plenty.

## Preview
    python3 -m http.server 8000

## Deploy (free subdomain)
- **GitHub Pages:** push this folder to a repo named `<username>.github.io` (or any repo, to get `/<repo>/`). Then go to Settings → Pages → Deploy from branch → `main` / root. `.nojekyll` is included.
- **Vercel:** run `npx vercel --prod` in this folder (preset "Other", no build command, output `.`).

All paths are relative, so it works at a domain root or under a subpath.
